## 배합과 환산

원본: 목살 1컵(130g), 신김치 3컵(390g), 물3컵(540ml), 청양고추2개, 대파약⅔대(70g), 마늘1큰술, 굵은고춧가루1큰술, 고운고춧가루½큰술, 국간장1큰술, 새우젓1큰술.
원본 인분은 미표기. 기존 편집 기준대로 원본=1–2인분, 두 배=3–4인분. 컵은 원본 물3컵540ml에 따라180ml. 김치는 포기 크기 환산 근거가 없어 종이컵 유지. 고기는 원본 무게130g/260g를 함께 표시하며 반 근300g으로 임의 변경하지 않음.

## 순서와 추가 설명

- 1.5cm 고기, 대파0.5cm 송송, 고추0.5cm 어슷은 원본 치수.
- 고기·물·새우젓 강불 → 끓으면 중약불10분 이상 → 줄어든 물 보충 → 김치·간장·마늘·고춧가루 → 끓으면 파·고추.
- 원본 마지막의 고춧가루 추가는 정량 미지정이므로 새 정량을 만들지 않고 본문에 설명. 기본 배합10개와 schema는 유지.
- 재료를 일부 남겨 간을 조절하는 안내, 고춧가루 한 종류 대체, 짤 때 물¼컵씩 추가하는 방법, 가위 손질은 편집 팁이며 원작자 배합으로 바꾸지 않음.
- 기존 자체 일러스트 5단계와 완성 그림 유지. 실제 조리·시식 검증 전.
