## 원본 배합과 환산

원본은 인분을 명시하지 않았다. 부추 200g 기준 원본을 밥에 곁들여 나눠 먹는 1–2인분, 정량 재료 전부 2배를 3–4인분으로 잡은 편집상 기준이다.

| 재료 | 원본 = 1–2인분 | 3–4인분 |
|---|---|---|
| 부추 | 200g | 400g |
| 당근 | ⅙개(50g) | ⅓개(100g) |
| 청양고추 | 4개(24g) | 8개(48g) |
| 부침가루 | 150g | 300g |
| 물 | 약 250ml | 약 500ml |
| 멸치액젓 | 1큰술(10g) | 2큰술(20g) |
| 건새우 | 20g | 40g |
| 식용유 | 3큰술(20g) | 6큰술(40g) |
| 간마늘 | 1큰술(15g) | 2큰술(30g) |
| 진간장 | 1큰술(10g) | 2큰술(20g) |
| 식초 | 1큰술(10g) | 2큰술(20g) |
| 황설탕 | ½큰술(5g) | 1큰술(10g) |

- 마지막 세 재료는 초간장용이며 반죽과 분리했다.
- 원본 물은 1½컵(250g)이다. 사이트 종이컵 180ml로 1½컵은 270ml이므로 컵 수를 그대로 옮기지 않았다. 물의 무게를 우선해 약 250ml = 종이컵 약 1⅖컵으로 표시하고 정확한 계량은 250ml를 따르도록 안내했다. 두 배는 약 500ml = 종이컵 약 2⅘컵이다.
- 부침가루 원본 1½컵(150g), 건새우 ½컵(20g)은 컵의 용량과 담는 정도를 확인할 수 없어 무게만 유지했다. 고형 재료 g을 ml로 바꾸지 않았다. 부추를 한 단·한 줌으로 추정하지 않았다.
- 숟가락과 g은 원본 그대로이며 가정 밥숟가락이나 표준 계량스푼 15ml와 동일하다고 단정하지 않는다.
- 원본 한국어 만드는 법 4번의 당근 중복은 재료표 및 영문 Directions와 대조해 한 번만 넣는 것으로 정리했다.

## 조리 순서와 편집자 추가

1. 원본 1번: 반죽용 물에 건새우 불리기. 원본에 불리는 시간 없음.
2. 원본 2–3번: 부추 5cm, 청양고추 잘게 다지기, 당근 채 썰기.
3. 원본 4번: 채소·간마늘·부침가루·불린 새우·물·멸치액젓 반죽.
4. 원본 5번: 식용유를 두르고 약불에서 얇게 펼치기.
5. 원본 6번: 펼친 다음 중불로 올려 노릇하게 굽기.
6. 원본 7번: 진간장·식초·설탕 초간장 곁들이기.

채소 물기 제거, 가볍게 반죽 섞기, 기름을 여러 장에 나눠 쓰기, 뒤집개로 받칠 크기, 뒤집는 상태 판단·속 익힘과 초간장 소량 찍기는 편집자가 덧붙인 안내로 본문에서 구분했다. 원본에 없는 시간이나 완성 장수는 만들지 않았다.

팁은 뒤집을 때 찢어짐 대처(189자), 분량 증가 시 장수·두께·불 조절(202자), 초간장·밥·생채소 곁들이기(204자)의 서로 다른 각도로 작성했다. 모두 편집자 추가임을 명시했다. 첫 팁은 인스타 카드에서도 사용할 수 있는 구체적인 실패 방지 안내다. instagram.hook은 불 조절을 묻는 23자 문구로 본문에서 답한다. cooked 필드는 추가하지 않았다.
