## 원본 순서와 확인 구간

- 감자전 1–3번: 감자를 껍질 벗겨 자르고 물과 곱게 갈기 → 가는 체에 걸러 10–15분 전분 가라앉히기.
- 감자전 4–7번: 윗물을 따라내 전분만 남기고 체의 감자와 섞기 → 꽃소금 넣기 → 고명 고추 가늘게 송송 썰기.
- 감자전 8–11번: 기름을 두른 넓은 팬을 중불로 달군 뒤 반죽을 한 국자씩 올리기 → 고추 고명 → 뒤집어가며 노릇하게 익혀 양념장과 내기.
- 양념장 1–2번: 고추를 약 0.3cm로 송송 썰고 진간장·식초와 섞기.
- 설명란에 부치는 분 단위 시간, 정확한 소금량, 인분이 없다. 임의 수치로 채우지 않았다.

## 편집상 환산과 추가 정보

- 원본 400g을 간식 1–2인분, 2배를 3–4인분으로 추정했다. 감자 개수는 크기에 따른 범위이므로 무게 우선 안내.
- 물은 180ml 종이컵 2컵/4컵. 숟가락은 원본 단위를 유지하고 가정용 밥숟가락 편차 안내. 액체 양념 무게를 임의 ml로 환산하지 않았다.
- 원본 순서를 3단계로 묶고 양념장을 부치기 전에 준비하도록 배치했다.
- 소금을 소량 넣고 작은 전으로 간 확인, 덜 매운 풋고추 대체, 2배 분량을 나눠 부치기 및 기름 나눠 쓰기는 편집자가 덧붙인 내용이다. 대체는 편집자 제안으로 명시.
- 직접 조리·시식 검증 전. cooked 필드를 추가하지 않았다.
- 기존 src/data 및 docs/recipes 확인: 같은 요리·영상 없음. 최근 감자조림(반찬), 볶음우동(면), 콩나물국(국)과 다른 분식·부침개로 선정. 기존 김치전과 주재료 및 반죽 방식이 다른 메뉴.

- `npm run build` → `npm run verify:built` → `audit_recipe.py --project . --slug paik-gamja-jeon` 순서로 통과.
- Chrome/Playwright 실제 브라우저에서 390px·1440px·320px 홈 링크로 상세 이동, 자체 이미지 네 장 naturalWidth=1536 및 로딩, 가로 넘침 없음 확인. 세 화면의 재료표 스크린샷 직접 확인.

- 검색용 title에 쉼표 앞 '레시피' 자동 삽입 확인. 기존 dailyRecipes 항목은 변경 전과 동일하고 새 항목 하나만 추가. 영상 ID 중복 및 새 cooked 필드 없음.
