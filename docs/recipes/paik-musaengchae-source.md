## 편집과 불확실성

- 원본 인분은 미명시. 반찬 기준 원본 절반을 1–2인분, 원본을 3–4인분으로 정한 편집상 기준이다. 혼자 소량 먹을 때 왼쪽 열을 반으로 줄일 수 있다고 안내했다.
- 컵은 사이트 180ml 종이컵 관례로 안내하되 원본에 컵 규격이 명시되지 않은 한계가 있어 원본 무게를 병기하고 정확한 계량에는 무게를 우선하도록 했다. 원작자도 컵·수저 크기에 따라 달라지니 g을 참고하라고 명시했다. 식초 40g을 40ml로 치환하지 않았으며 고형 재료 g=ml 환산도 없다.
- 원본은 채칼 손질. 그림은 칼 손질이며 편집상 대안을 본문에 명시했다. 두께의 임의 수치를 만들지 않았다.
- 소금 일부를 남겨 간을 보며 넣는 방법, 볼 크기와 나누어 무치기, 수분이 생겼을 때의 간 조절은 편집자가 덧붙였다. 기본 표 배합은 그대로다.
- 깨소금을 볶은 참깨로 준비하는 방법은 ‘편집자 제안’으로 표시했다. 원작자의 대체 배합처럼 쓰지 않았다.
- 팁 세 각도: 실패·간 조절 / 분량 조절 / 재료 대체. 각 190/201/201자.
- 직접 조리·시식 경험, cooked 필드, 가짜 평점·공개일·조리 시간 없음.

## 검증 결과

- `npm run build` → `npm run verify:built` → `python3 .agents/skills/youtube-recipe-blog/scripts/audit_recipe.py --project . --slug paik-musaengchae` 통과. 임베드 대체 후 같은 순서로 재검증했다.

- 원본 썸네일 maxresdefault.jpg: HTTP 200, 실제 1280×720.
- Playwright + 로컬 Chrome, 390px / 320px / 1440px: 홈에서 새 상세 클릭 이동, 모든 본문 이미지 1536×1024 로딩, 가로 넘침 없음. 모바일 만드는 순서 바로가기 작동. 재료표 스크린샷을 직접 확인했다. 기존 김치찌개 상세와 재료 섹션도 확인했다.
- 부모 페이지에서 외부 요청을 차단하지 않고 공식 youtube-nocookie iframe 재생 버튼을 클릭했다. ‘로그인하여 봇이 아님을 확인하세요’가 표시되고 video.currentTime=0, paused=true, readyState=0이었다. 따라서 이 글의 embed만 false로 바꿔 현행 원본 썸네일+YouTube 링크 대체 UI를 적용했다. 공개 방문자의 재생 가능 여부는 보장하지 않는다.
- HEAD의 dailyRecipes와 새 목록의 두 번째 이후를 deepEqual로 대조해 기존 데이터 동일 확인. 전체 30→31건, 영상 ID 31개 모두 고유, 새 cooked 필드 없음. 최종 diff는 새 글 삽입뿐이며 기존 콘텐츠·공통 디자인·레이아웃 변경 없음.
- 이미지 네 장 직접 시각 검수, 팁 길이와 배합 환산·출처 구분 수동 대조, git diff --check 통과.
