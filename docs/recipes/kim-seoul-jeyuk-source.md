## 원본 배합과 순서 (내용 요약)

앞다리살 600g. 설탕 2스푼과 간장 2스푼으로 밑간하고 약 30분 재운다.
고추장 2, 고춧가루 2, 맛술 3, 물엿 2, 굴소스 1, 다진 마늘 1스푼을 따로 섞어 같은 동안 숙성한다.
팬에 식용유를 두르고 고기를 먼저 익힌 뒤 양념장을 넣는다.
고기가 거의 익으면 채 썬 양파 1개와 길게 썬 대파 1대를 넣는다.
양파가 투명해진 후 어슷 썬 청양고추 2개와 통깨로 마무리한다.
식용유·통깨 양, 불 세기, 볶는 시간, 인분, 구체적인 손질 치수는 원본에 없다.

## 환산·편집한 부분

- 원본 600g을 돼지고기 한 근으로 표기. 3–4인분은 원본, 1–2인분은 고기와 정량 재료 절반. 인분 구분은 편집상 추정이며 직접 조리 전이다.
- 한 근 환산 참고: 다누리 한국요리 안내의 장보기 설명 https://liveinkorea.kr/download.do?uuid=201701171751000432.pdf (돼지고기 한 근은 보통 600그램).
- ‘스푼’은 사이트 표기대로 밥숟가락 큰술로 안내하되 정확한 15ml/수북함 여부를 원본이 지정했다고 하지 않는다.
- 양파 약 0.5cm, 대파 약 5cm와 세로 가르기, 중불부터 팬 상태를 보며 조절하는 설명은 편집자 보충. 본문에서도 구분한다.
- 식용유·깨를 정량으로 지어내지 않음. 컵으로 고기 무게를 환산하지 않음.

## 제목과 후기 근거

‘1,000만 뷰’는 확인한 조회수의 보수적 표현이다. 조회수가 맛이나 성공을 보증한다고 쓰지 않는다.
아래 일부 시청자 경험을 요약해 소개하며 사이트 작성자의 직접 조리 후기나 전체 시청자의 평가로 바꾸지 않는다. 별점 구조화 데이터에도 넣지 않는다.

- 정착 후기: https://www.youtube.com/watch?v=PlLBBlFEmLg&lc=UgzC7iWBTU9zBWUPYAB4AaABAg — 여러 제육 레시피를 시도한 뒤 정착했고 식당 맛과 비슷하다는 시청자 반응.
- 반복 조리와 물엿 조절: https://www.youtube.com/watch?v=PlLBBlFEmLg&lc=UgwaeLyd0oCmJLb3X5V4AaABAg — 열 번 정도 만들었다는 반응, 밑간 설탕은 유지하고 물엿은 원본 2스푼에서 1스푼으로 줄였다고 함. 이를 반 분량에서는 ½큰술로 환산. 원작자 배합이 아닌 시청자 변형으로 표시.

## 임베드 확인과 대체 처리

2026-09-28, 실제 로컬 페이지에서 외부 요청을 차단하지 않고 확인.
제육 영상은 youtube-nocookie.com 및 youtube.com 임베드에서 ‘이 동영상은 볼 수 없습니다’로 표시된다.
실제 페이지 origin과 enablejsapi, playsinline을 명시해도 `previewPlayabilityStatus.status: UNPLAYABLE`이다.
같은 브라우저·부모 페이지에서 김치찌개 영상 ID로 바꾸면 `status: OK`, `playableInEmbed: true`로 로드된다.
원작자 설정 때문이라고 단정할 근거는 없으며 지역·계정 등 모든 환경에서의 실패를 뜻하지 않는다.
제육 본문은 실패하는 iframe 대신 명시적인 원본 썸네일 링크와 고정 댓글 링크를 표시한다.
김치찌개 임베드는 유지한다. 이전 UI 검증은 영상 요청을 차단했으므로 실제 재생 검증으로 간주하지 않는다.
