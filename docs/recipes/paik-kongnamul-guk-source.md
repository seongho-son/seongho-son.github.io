## 배합 대조

| 재료 | 원본 약 4인분 = 글 3–4인분 | 글 1–2인분 = 원본 절반 |
|---|---|---|
| 콩나물 | 300g | 150g |
| 정수물 | 약 11컵(2L) | 1L |
| 대파 | 약 ½대(40g) | 약 ¼대(20g) |
| 간 마늘 | 1큰술(20g) | ½큰술(10g) |
| 꽃소금 | 약 1큰술(10g) | 약 ½큰술(5g) |
| 국간장 | 1½큰술(15g) | ¾큰술(7.5g) |
| 청양고추 | 1개(10g) | ½개(5g) |
| MSG 선택 | 약 ⅙큰술 | 약 ¹⁄₁₂큰술 |

MSG는 원본 조리법 3번의 선택 안내다. 맛소금은 꽃소금의 대체이므로 기본 배합에 중복 추가하지 않았다. 물은 리터 수치를 우선하여 180ml 종이컵 약 5.6컵/11.1컵으로 환산했다. 콩나물의 g을 부피로 바꾸지 않았다. 원본 숟가락과 집 밥숟가락의 차이를 공통 계량 안내에 남겼다.

## 순서와 편집 구분

1. 원본 1–2번 → 글 1단계: 콩나물을 가볍게 세척하고 체에 밭쳐 물기를 제거. 대파·청양고추는 0.3cm 송송 썰기.
2. 원본 3번 → 글 2단계: 물이 끓으면 콩나물·국간장·마늘·꽃소금을 넣어 강불에 끓이기. MSG 선택. 국간장을 취향에 맞게 조절하라는 원본 지시 유지.
3. 원본 4번 → 글 3단계: 다시 끓으면 중불로 약 5분, 대파·고추를 넣고 약 1분 더 끓이기.

국간장 일부를 남겨 간 보기, 작은 분량의 익힘 확인, 완성 후 불을 끄고 바로 담는 가정용 제안은 편집자 팁으로 명시했다. 원본은 식당에서 건더기와 국물을 분리하면 식감을 살릴 수 있다고 안내한다. 총 조리 시간·평점·칼로리는 추정하지 않았다. 발행일도 생성하지 않았다.

## 최종 검증

- `npm run build` → `npm run verify:built` → `python3 .agents/skills/youtube-recipe-blog/scripts/audit_recipe.py --project . --slug paik-kongnamul-guk` 통과. 홈 목록·RSS·상세 canonical·Recipe JSON-LD·단계 이미지·사이트맵·애드센스 연결을 확인했다.
- Chrome/Playwright 390px·1440px·320px: 원본 썸네일 로드, 목록 제목 클릭으로 상세 이동, 자체 이미지 네 장 디코딩, 두 인분 재료 표시, 만드는 순서 바로가기, 가로 넘침 없음. 재료 영역 스크린샷을 직접 읽었다. 기존 김치찌개는 390px·1440px에서 제목·가로 넘침 없음 확인.
