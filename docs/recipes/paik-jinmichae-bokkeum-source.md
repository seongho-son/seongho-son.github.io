## 근거와 환산

설명란 [재료] 9종과 [만드는 법] 1–3번을 기준으로 했다. 인분은 원본에 없으므로 반찬으로 먹는 편집상 인분이다. 1–2인분은 원본의 1/2, 3–4인분은 원본 그대로다.

| 재료 | 원본 / 3–4인분 | 1–2인분 |
|---|---|---|
| 오징어채 | 200g | 100g |
| 고추장 | 1/3컵(66g) | 33g |
| 고운 고춧가루 | 1/4컵(18g) | 9g |
| 참기름 | 3큰술(24g) | 1½큰술(12g) |
| 물엿 | 1/3컵(60g) | 30g |
| 황설탕 | 1/4컵(28g) | 14g |
| 물 | 1/6컵(35g) | 17.5ml |
| 마요네즈 | 1/3컵(50g) | 25g |
| 통깨 | 3g | 1.5g |

- 물만 1g≈1ml로 환산했다. 180ml 종이컵 기준 17.5ml는 약 1/10컵, 35ml는 약 1/5컵이며 정확한 ml를 병기했다.
- 원본 컵의 용량·재료 담는 정도를 확정할 수 없어 양념의 g을 유지했다. 고형 재료를 1g=1ml로 바꾸거나 근거 없는 숟가락 환산을 하지 않았다. 참기름 큰술은 원본 단위로 가정 밥숟가락과 동일하다고 단정하지 않았다.
- 원본 자막은 양념을 일부 남겼다가 취향에 따라 더하도록 안내한다. 표는 준비량이며 모두 넣어야 하는 양으로 설명하지 않았다.

## 순서와 자막 확인 구간

자막에는 타임스탬프가 없으므로 시간 위치를 지어내지 않았다.

1. 초반 제품 설명: 양념된 오징어채를 사용. 이미 부드러운 제품은 불리지 않으며 딱딱한 경우만 약 5분 물에 담근다.
2. 양념 시연: 고추장·물·설탕·고춧가루·물엿을 팬에 섞고 약불에서 설탕이 녹을 때까지 끓인다. 끓기 시작하면 불을 끈다. 센 불이면 수분이 빨리 줄어든다고 설명한다.
3. 볼에서 버무리기: 마요네즈를 오징어채에 먼저 섞는다. 자막은 선택 가능하지만 권장하며, 데이터는 설명란의 마요네즈 포함 배합을 사용했다.
4. 양념을 일부 남겨가며 무친 뒤 참기름과 통깨로 마무리한다. 설명란 1–3번에는 참기름·통깨 투입 시점이 생략되어 자막의 마무리 시연을 반영했다.

물기 제거 안내, 작은 팬 선택, 되직한 양념을 소량의 물로 풀기, 곁들이기는 편집자 안내로 표시했다. 팁은 실패 방지·분량별 도구/불·곁들이기의 세 각도로 191/191/198자다. 첫 팁은 인스타 팁 카드용으로도 사용할 수 있는 구체적인 조절 안내다. hook 25자의 질문은 본문 3단계에서 답한다.
