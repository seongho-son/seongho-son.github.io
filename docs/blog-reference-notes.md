# 블로그 표현과 화면 구성 참고

조사일: 2026-09-28. 사이트 적용과 구분하여 참고 사항을 기록한다.

## 실제 글의 말투

- 초보새댁 효니라이프: https://hyonislog.tistory.com/66
  - 김치찌개 레시피를 고른 사연 사이에 `(감격..!)`, `:)`, `ㅎㅎ` 같은 짧은 반응이 들어간다.
  - 레시피 설명과 개인의 반응이 이어지는 문장 구성을 참고한다. 작성자의 실제 경험을 우리 글의 경험으로 옮기지 않는다.
- 일미 레시피: https://tastyrecipes.tistory.com/42
  - 남편이 요리하는 상황과 대화를 앞뒤에 배치해 일기처럼 읽히는 글이다.
  - 도입과 마무리의 말투 참고용. 감정 스티커 사용 사례로 확인한 것은 아니다.

## 감정 이미지 참고 — 블로그 본문 사례와 별도의 스티커 카탈로그

- 하다HADA, 꿀때지의 말랑한 블로그: https://ogqmarket.naver.com/artworks/sticker/detail?artworkId=62776e2e4b5e3
  - 미리보기에서 같은 돼지 캐릭터가 웃음, 하트, 불꽃 등의 반응을 보이고 재료 소개·손질 동작도 표현한다.
  - 캐릭터를 반복해서 쓰되, 문맥에 맞는 표정과 동작을 고르는 방식이 브랜드와 어울린다.
- 아키하나, 요리콘: https://ogqmarket.naver.com/artworks/sticker/detail?artworkId=5bcb06107cc07
  - 요리 시작, 재료 손질, 양념장 만들기, 팁, 완성 등 조리 흐름을 작은 그림과 글자로 표현한다.
  - 절차 안내용 이미지와 감정 반응용 이미지를 구분하는 데 참고한다.
- 위 상품은 네이버 사용처를 안내하는 스트리밍 라이선스 상품이다. 외부 사이트에 재사용할 에셋으로 구매하거나 다운로드한 것이 아니다.

## 우리 글에 제안하는 사용법 (미적용)

- 글마다 2–3개 정도의 작은 정지형 캐릭터 그림부터 시작한다. 빈도는 조사 결과의 통계가 아닌 디자인 제안이다.
- 도입의 고민, 조리 중 주의할 부분, 완성의 기쁨처럼 반응할 이유가 있는 곳에 둔다.
- 예: 물 보충 설명 옆에 당황한 작은 캐릭터 + “처음 물을 전부 다시 붓는 건 아니에요!”
- 재료표, 목차, 단계별 설명 그림에는 감정 장식을 섞지 않아 요리 중 빠르게 읽을 수 있게 한다.
- 사이트 이름에 맞는 작은 도깨비 또는 밥그릇 캐릭터를 자체 제작하는 방향을 제안한다. 기존 캐릭터 복제는 하지 않는다.

## 화면별 구성 (적용)

- 1024px 이상: 최대 1160px 사이트 폭, 가로형 헤더, 본문과 오른쪽 고정 목차. 목차에서 재료 및 5개 단계 직접 이동.
- 1024px 미만: 한 열의 본문, 상단 고정 재료·순서 바로가기. 좁은 화면은 좌우 20px 여백과 44px 이상 링크 높이.
- 모든 화면에서 1–2인분과 3–4인분 표를 함께 보여준다. 메뉴 밑줄은 사용하지 않는다.
