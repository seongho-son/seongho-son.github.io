## 사이트 내부 반영

- 홈은 레시피 목록, 상세는 `/recipes/kimchi-jjigae/`로 분리.
- 제목: 돼지고기 김치찌개 레시피 — 백종원 따라 오늘 저녁 뚝딱!
- 종이컵·인분은 본문의 편의성으로 제공. 수요가 검증된 주력 키워드로 취급하지 않는다.
- `김치찌개 짤 때`는 기존 글의 소제목·고정 목차로 연결. 별도 유사 글을 양산하지 않는다.
- 상세 canonical, 공유용 설명·이미지, Recipe의 단계별 URL과 이미지 반영.
- 재료·단계 데이터를 상세와 RSS에서 공유. 확인하지 않은 조리 시간·평점·발행일을 만들지 않는다.
- RSS `/rss.xml`, 사이트맵 `/sitemap-index.xml`.

## 네이버

- 서치어드바이저 소유 확인 후 사이트맵과 RSS 제출. 수집·색인·노출·클릭 확인.
- 독립 웹사이트이므로 네이버 블로그 문서 수 기반 등급을 웹문서 SEO 난도로 해석하지 않는다.
- 김치찌개 레시피, 돼지고기 김치찌개 레시피, 참치김치찌개 레시피, 스팸김치찌개 레시피의 검색 화면에서 외부 사이트 노출 위치를 조사한 뒤 발행 우선순위 결정.
- 블로키 공개 수요 구간은 네이버 검색광고 기반 자료이며 실시간 직접 조회값이 아니다. Google 수요로 전용하지 않는다.
- 참고: https://blokey.co.kr/k/김치찌개 및 https://blokey.co.kr/k/백종원%2B김치찌개
- 공식 가이드: https://searchadvisor.naver.com/guide/seo-basic-intro

## 구글

- Search Console 소유 확인 후 사이트맵 제출, 상세 URL 검사.
- Rich Results Test로 실제 공개 상세 페이지를 검사. 로컬 JSON/링크 검사는 이를 대신하지 않는다.
- 키워드 플래너 대한민국·Google 검색 조건으로 후보 검색량을 별도 확인. 광고 경쟁도를 자연검색 난도로 해석하지 않는다.
- 레시피의 조리 검증·독창적인 설명과 직접 촬영 사진을 보강.
- 김치찌개 짤 때·신맛 등은 아직 수요 미검증. 기존 글의 검색 노출/독자 질문을 보고 별도 콘텐츠 필요성을 판단.
- 4주 단위로 검색어·페이지·기기별 노출과 클릭을 비교. 낮은 CTR은 같은 검색어와 비슷한 순위 조건에서 비교.
- https://support.google.com/google-ads/answer/3022575?hl=ko
- https://developers.google.com/search/docs/appearance/structured-data/recipe

## 공개 배포 후 필요한 작업

2026-09-28 GitHub Pages 공개 배포 완료. 홈·레시피·RSS·사이트맵·Google 소유확인 파일·ads.txt HTTP 200, 폐기된 /guides/ 및 /tools/ HTTP 404 확인. Search Console은 제공된 속성 주소로 접근했으나 로그인 전 소개 페이지로 이동하여 계정 내 제출은 수행하지 못했다.

1. https://gibalpeople.com/recipes/kimchi-jjigae/ 의 HTTP 200, canonical, 실제 이미지 접근 확인.
2. 양쪽 검색 도구에 사이트맵 제출, 네이버에는 RSS 추가 제출.
3. Google URL 검사 및 Rich Results Test 실행.
4. 폐기된 정부지원 URL이 HTTP 404로 응답하는지 확인. 무관한 홈으로 일괄 리다이렉트하지 않는다.
5. 실제 공개일, 조리 검증 결과는 확인한 뒤 입력.

운영 계정 데이터 확보 전에는 검색량 미확인을 0으로, 색인 요청을 노출 보장으로 표시하지 않는다.
